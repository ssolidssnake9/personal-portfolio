# personal-portfolio

Responsive personal portfolio landing page — skills, bio, projects, experience timeline, printable résumé, and contact. Single-file build (`index.html`, no dependencies, no build step), hosted free on GitHub Pages.

**Live:** https://ssolidssnake9.github.io/personal-portfolio/

## Deploy

Push to `main`, then enable Pages (Settings → Pages → Deploy from branch → `main` / `/`), or via API:

```
POST /repos/ssolidssnake9/personal-portfolio/pages
{"source":{"branch":"main","path":"/"}}
```
